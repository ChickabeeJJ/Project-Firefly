# Reference analysis (Milestone 0)

Evidence: `reference-observations.md` (timestamped), `reference-gameplay-flow.md`,
`reference-style-study.md`. Tooling: `tools/contact-sheet.sh`.

| Category | Answer from the footage |
|---|---|
| Game identity | Turn-based side-view party RPG where actions are cards dealt into a hand; collection via summons; story-driven stage progression. The player is trying to clear stages (defeat all waves within a round limit) and grow a roster. |
| Core verbs | **Select** cards into action slots; **merge** identical cards; **target** an enemy; **unleash** an ultimate; in the meta, **summon** and **assemble a team**. |
| Controls | Mouse clicks/taps only in battle; no keyboard observed. Four diamond buttons for card list, speed, auto and pause. |
| Gameplay loop | Deal → choose N cards (N = action slots) → the queue resolves automatically → telegraphed enemy actions → next round. Wave clear → next wave or victory. |
| Character behaviour | Idle in place with a slight sway; on cast, rings/aura appear around the caster and the effect travels to the target; hit targets flinch; defeated enemies dissolve. No free movement. |
| Camera | Fixed. Depth via darkening/vignette and VFX, not camera moves. |
| Spatial layout | One shallow stage: enemies one side, party the other, 3–4 units per side on a slight diagonal. |
| Challenge | Enemy damage over rounds and the round limit; enemy intent icons are visible during planning (2:24). |
| Feedback | Scene dimming, gold rings, beams and bursts, floating status labels, large italic damage numbers, gold totals. |
| Difficulty | Increases via recommended level and stage modifiers ("Bloodtithe", "Apocalyptic Flood" chips at 2:15). |
| Rewards | Victory screen with objective stars, EXP bar, item tiles; summon reveals; unlocked next stage on the timeline. |
| Visual language | Desaturated teal-grey stages; cream/orange/gold UI; serif typography; pop-art card illustrations; painterly portraits. |
| Interface | Corner-anchored HUD, hand at the bottom, action slots top-centre, tooltips bottom-left during casts. Menus: one big character + information panel. |
| Audio | Not analysed: the capture's soundtrack was not reviewed in detail (uncertain). We design an original audio bible. |
| Replay | Star objectives, summon anticipation, new stage unlocks, collecting characters. |

## What we preserve (experience, not content)

- Choosing a few cards from a dealt hand each round, with merges rewarding patience and order.
- An ultimate that charges by playing that character's cards.
- Telegraphed enemy actions you can plan around.
- Cream-paper-and-serif presentation, moody stages, gold payoff moments.
- A ceremonial summon with a rarity tease before the reveal.
